01

Flood detection from satellite radar

A U-Net segmentation model with a ResNet34 encoder that finds flooded terrain in Sentinel-1 radar imagery, trained on the Sen1Floods11 dataset. Radar sees through cloud cover, which matters because the storms that cause floods are usually the same ones blocking optical satellites — but the signal is noisy and hard to label, so the model has to hold up on messy real-world scenes rather than just clean examples. It reaches a mean IoU of 0.79 and runs as a live, containerized API on Google Cloud Run.

02

Volatility forecasting

A comparison of three approaches to forecasting S&P 500 volatility — GARCH, XGBoost, and LSTM — evaluated with walk-forward validation and QLIKE loss, the metric that actually reflects how a volatility forecast will be used, rather than plain squared error. XGBoost came out ahead across every metric tested, which says as much about the limits of the classical model on this data as it does about gradient boosting.

03

Bayesian redshift distribution modeling

Every large-scale structure measurement depends on knowing how far away the galaxies actually are, and photometric surveys only give a rough estimate of that. This project fits Gaussian mixture models to photometric redshift distributions using MCMC sampling, uses the Bayesian information criterion to decide how many components the data actually supports, and corrects iteratively for selection bias — the kind of estimation problem that shows up anywhere a sample isn't quite representative of the population behind it.
